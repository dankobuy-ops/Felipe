Para escanear y ordenar los discos de esta PC, sigue estos 3 pasos:

1

Descarga el motor local

Un ejecutable ligero (~6 MB) que le permite a esta web leer y organizar tu sistema de archivos de forma completamente local.

⬇ Descargar backend.exe ¿Tienes Python? pip install flask && python backend.py
2

Ejecuta el motor en segundo plano

Haz doble clic sobre backend.exe. Aparecerá una ventana de terminal que debe permanecer abierta mientras usas la app.

╔══════════════════════════════════════╗ ║ 🗂 Disk Organizer — Backend v1.1 ║ ║ Escuchando en localhost:5000 ║ ║ Mantén esta ventana abierta ║ ╚══════════════════════════════════════╝
3

Verifica la conexión

Una vez que el motor esté ejecutándose, haz clic para conectar y empezar a escanear.

❌ No se detectó el motor en localhost:5000. Asegúrate de que la ventana de terminal esté abierta.

🔍 Escanear disco

Escribe la ruta a analizar. Se omiten automáticamente las carpetas de sistema.

Rutas de ejemplo: D:\  ·  C:\Users\Danko  ·  E:\Fotos

Leyendo archivos… esto puede tomar unos minutos en discos grandes.
